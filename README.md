# MyGameNovella

MyGameNovella — прототип редактора визуальных новелл на C# / Avalonia и
графического runtime-ядра на C++ / SFML. Редактор позволяет собирать историю
из узлов, задавать их свойства через форму и проверять сцену в отдельном окне
движка.

> **Текущий статус:** проект уже умеет редактировать и сохранять граф сцен и
> запускать его в preview и собирать Windows x64 пакет автономной игры.
> Перед публичным выпуском всё ещё нужна GUI-приёмка на целевых Windows
> системах и подготовка собственных ресурсов/истории игры.

## Запуск и сборка

- Редактор: откройте `EngineEditor/EngineEditor.csproj` в Visual Studio или
  выполните `dotnet run --project EngineEditor/EngineEditor.csproj`.
- Отдельный player: выполните
  `dotnet run --project EnginePlayer/EnginePlayer.csproj -- --play "путь-к-проекту.novel"`.
  Если путь не указан, player ищет `Content/game.novel` рядом с исполняемым
  файлом. Player запускает только игру, без редактора.
- Ядро: соберите CMake-проект в `EngineCore`. Для сборки нужны CMake, C++17,
  SFML 3 с компонентами Graphics, Window, System и Audio, совместимые с
  Windows и используемым компилятором.
- Для preview редактору нужна собранная `EngineCore.dll` в доступном для
  загрузчика месте. Проект редактора пока не собирает и не упаковывает эту
  DLL автоматически.

## Работа с проектом

1. После запуска редактор показывает демонстрационный граф. Узлы и связи
   можно создавать из палитры и перемещать на графе; колесо мыши меняет
   масштаб, перетаскивание фона перемещает холст, соединение создаётся
   перетаскиванием от узла к узлу.
2. Нажмите **Открыть**, чтобы выбрать файл `.novel`, или **Сохранить**, чтобы
   выбрать путь сохранения. Ошибки загрузки и сохранения отображаются в
   статусе проекта; неудачная загрузка не заменяет уже открытый граф.
3. Новые файлы — JSON-документы с `formatVersion: 1` и массивом `scenes`.
   Старые файлы, содержащие JSON-массив сцен, читаются как формат до версии 1.
   Их связи по уникальным именам переводятся в ссылки по стабильным ID; при
   неоднозначном или неизвестном адресате загрузка/сохранение сообщает об
   ошибке, а не выбирает случайную сцену.
4. Имена сцен используются в форме для отображения и ручного ввода переходов,
   но сохранённые связи привязаны к ID. Если вручную вводите адресата,
   укажите его точное уникальное имя либо соедините узлы перетаскиванием.

## Узлы и игровая логика

- **Сцена (диалог):** имя узла, имя персонажа, текст, цвет заголовка, фон,
  спрайт, координаты персонажа, анимация и музыкальный файл. Прямой переход
  задаётся ссылкой на следующую сцену.
- **Узел выбора:** содержит варианты с текстом кнопки и целевой сценой.
  Перетяните соединение между узлами или впишите имя адресата в инспекторе.
  Нативное ядро отображает не более четырёх вариантов одновременно.
- **Условие:** сравнивает числовую переменную с числом оператором `==`, `!=`,
  `>`, `<`, `>=` или `<=` и переходит по одной из двух обязательных ссылок.
  Не заданная переменная считается равной нулю; неверные операторы и числа
  редактор показывает как ошибки проверки проекта.
- **Системное действие:** выполняет одну встроенную команду. В поле команды
  укажите имя команды, двоеточие и её аргумент, например `SetVar: HP - 10`.
- **Импорт ресурсов:** кнопки «Импорт» рядом с фоном, спрайтом и музыкой
  копируют выбранный файл в `Assets` рядом с `.novel` и записывают
  переносимый относительный путь. Перед импортом сохраните проект.
- **Звуковые эффекты:** у действия выберите «Импортировать звуковой эффект»;
  редактор добавит команду `PlaySound: Assets/...`. Эффекты играют независимо
  от фоновой музыки, одновременно поддерживается до 16 экземпляров.
- **Постепенный вывод текста:** ползунок скорости в панели Preview управляет
  скоростью показа реплики; значение 0 показывает её целиком. Первый щелчок
  по диалогу раскрывает остаток реплики, следующий переходит дальше.
- **Сохранение игры:** кнопки `SAVE` и `LOAD` в окне игры открывают меню из
  шести слотов с названием сцены и временем сохранения. `F5` быстро записывает
  слот 1, `F9` быстро загружает слот 1. Сохраняются сцена, числовые переменные
  и история уже просмотренных реплик. Файлы лежат в `%LOCALAPPDATA%` в папке
  `MyGameNovella/Saves`; сохранения разных расположений проекта разделяются.
  Если проект изменён и сохранённая сцена больше не существует, загрузка
  сообщит об ошибке вместо случайного перехода.
- **Lua в узле действия:** необязательное многострочное поле принимает
  пользовательский Lua-скрипт. Скрипт выполняется отдельно от UI и имеет
  строгий профиль без стандартных `io`, `os` и доступа к .NET. Выполнение
  отделено от UI, но жёсткий лимит инструкций скрипта пока не реализован;
  не запускайте пользовательский код из недоверенных источников и избегайте
  бесконечных циклов.
- В тексте реплики и кнопках выбора можно подставлять числовые переменные
  записью `{HP}`. Неизвестное имя оставляется как текст в фигурных скобках.
- **Переходы:** прямые ссылки, варианты выбора и ветви условия задают ход
  истории. Связи используют ID сцен. Диалог без следующего перехода является
  концом истории; runtime не угадывает адресата по порядку списка.
- Удаление сцены удаляет связанные с её ID переходы. Проект должен содержать
  хотя бы одну сцену; ID сцен должны быть уникальны.

### Системные команды

Команда задаётся в форме `Имя: аргумент`:

| Команда | Действие |
| --- | --- |
| `PlayMusic: путь` | Запускает зацикленную фоновую музыку. |
| `PlaySound: путь` | Проигрывает однократный звуковой эффект поверх музыки. |
| `StopMusic` | Останавливает фоновую музыку. |
| `StopSound` | Останавливает звучащие эффекты, не затрагивая музыку. |
| `Volume: 0..100` | Устанавливает громкость музыки. |
| `FadeOut: секунды` | Плавно уменьшает громкость музыки, затем останавливает её. |
| `FontSize: число` | Задаёт размер текста в preview. |
| `SetVar: имя = число` | Задаёт числовую переменную; доступны также операции `имя + число` и `имя - число`. |
| `Shake: секунды` | Запускает тряску окна preview. |
| `Flash: #RRGGBB` | Показывает короткую цветовую вспышку поверх сцены. |

Команды и числовые значения переменных реализованы в C# редакторе. Редактор
проверяет переходы и условия перед сохранением/preview, но отдельной панели
просмотра и редактирования переменных пока нет.

Lua-функции имеют имена `get_var(name)`, `set_var(name, value)`,
`play_music(path)`, `play_sound(path)`, `stop_music()`, `stop_sound()`, `set_volume(value)`,
`fade_music(seconds)`, `set_font_size(integer)`, `shake(seconds)` и
`flash("#RRGGBB")`. Путь к музыке относительно каталога файла проекта.
Пример:

```lua
set_var("HP", get_var("HP") + 5)
play_music("audio/theme.ogg")
```

Ошибки компиляции/выполнения Lua показываются в статусе редактора. Игровые
переменные сохраняются в слот игры горячими клавишами F5/F9, но не в самом
редакторском файле сценария.

## Preview, медиа и визуальные эффекты

- **Запустить движок / Остановить:** открывает или завершает native preview.
  Щелчок в окне продолжает диалог, щелчок по кнопке выбора выбирает вариант.
- Игровое окно оформлено как отдельный экран новеллы: компактная верхняя панель
  управления, полупрозрачная панель реплики, имя персонажа, анимированный
  индикатор появления текста и выразительные кнопки выбора. Длинные реплики и
  варианты переносятся по ширине окна.
- **SAVE / LOAD:** открывают экран выбора одного из шести слотов. В карточках
  показываются сцена и время сохранения; повреждённые и несовместимые сохранения
  отмечаются и не загружаются.
- **HISTORY** (`L`): открывает историю до 12 последних реплик; `Esc` или щелчок
  закрывает её.
- **AUTO** (`A`): сам показывает реплики и продолжает историю, но останавливается
  на выборе.
- **HIDE UI** (`H`): скрывает окно диалога и выборы, оставляя фон/персонажа и
  верхнюю панель. Повторное нажатие возвращает интерфейс.
- **SKIP** (`T`) включает быстрое автоматическое пропускание только ранее
  просмотренных диалогов; оно останавливается на выборе. Удерживайте `Space`
  для временного пропуска; новые реплики не пропускаются. История просмотренных
  реплик сохраняется в слотах игры.
- **Размер текста:** ползунок редактора задаёт размер шрифта preview; второй
  ползунок управляет постепенным раскрытием реплики.
- **Громкость и Fade-out:** управляют текущей фоновой музыкой; `PlayMusic`
  загружает файл, включает зацикливание и начинает воспроизведение.
- **Анимация персонажа:** `FadeIn`, `SlideLeft`, `SlideRight` и `Bounce`.
  Переходная анимация длится около 0,4 секунды.
- **Shake / Flash:** кратковременные экранные эффекты; доступны системными
  командами.
- **Ресурсы:** поля фона, спрайта и музыки имеют кнопку импорта в проектную
  папку `Assets`. Наличие явно упомянутых ресурсов проверяется при сохранении,
  запуске и экспорте. Шрифт ядра загружается как `arial.ttf` из каталога
  `basePath`; при отсутствии пакета на Windows используется системный шрифт.

## Экспорт автономной игры

Скрипт `scripts/publish-game.ps1` собирает self-contained Windows x64 player,
копирует проект и ресурсы, включает `EngineCore.dll` и подходящие SFML DLL,
затем создаёт папку игры и ZIP-архив. В `NativeRuntimeDirectory` должны лежать
Release-сборка `EngineCore.dll` и соответствующие ей Release-библиотеки SFML
(`sfml-*-3.dll` без суффикса `-d`). Для локальной отладки скрипт также
поддерживает `-NativeConfiguration Debug`, но такой пакет не предназначен для
релиза.

Пример запуска из корня репозитория (замените пути проекта, содержимого и
нативного runtime на свои):

```powershell
.\scripts\publish-game.ps1 `
  -ProjectFile ".\MyNovel\Story.novel" `
  -ContentDirectory ".\MyNovel" `
  -NativeRuntimeDirectory ".\release-native" `
  -FontFile "$env:WINDIR\Fonts\arial.ttf" `
  -OutputDirectory ".\dist" `
  -GameName "MyNovel" `
  -NativeConfiguration Release
```

Папка `MyNovel` и `MyNovel.zip` появятся внутри `OutputDirectory`. ZIP можно
распаковать и запустить на Windows x64 без установленного .NET SDK; в
`README.txt` внутри пакета перечислены основные сведения и сторонние
компоненты. Перед публикацией проверьте игру на чистой Windows-машине и
убедитесь, что используемые SFML DLL соответствуют компилятору и конфигурации
нативного ядра.

## Архитектура

- `EngineEditor/Views/MainWindow.axaml` — интерфейс графа, инспектора и
  runtime-контролов.
- `EngineEditor/Views/MainWindow.axaml.cs` — редактирование графа, переходы,
  переменные и команды, запуск preview, сохранение и загрузка проекта.
- `EngineEditor/Models/SceneModel.cs` и `ChoiceModel.cs` — данные узлов и
  вариантов выбора.
- `EngineEditor/Models/ProjectFileService.cs` — чтение и запись версии
  проекта, миграция прежнего массива сцен и проверка ссылок.
- `EngineEditor/EngineWrapper.cs` — C# P/Invoke-объявления для `EngineCore.dll`.
- `EngineCore/EngineCore.cpp` — окно SFML, отрисовка, ввод, музыка, базовые
  анимации и эффекты.
- P/Invoke-вызовы обновления сцены, команд, аудио и эффектов ставятся в очередь
  и выполняются на потоке native preview; это отделяет ввод Avalonia от цикла
  SFML.

### Функции C++-ядра

Эти функции экспортирует `EngineCore.dll`; управляемые объявления находятся
в `EngineEditor/EngineWrapper.cs`:

| Функция | Назначение |
| --- | --- |
| `InitEngine(width, height, title, basePath)` | Создаёт SFML-окно и загружает `arial.ttf` из `basePath`. |
| `ShutdownEngine()` / C# `CloseEngine()` | Останавливает музыку и закрывает окно. |
| `UpdateScene(background, text, characterName, sprite, x, y)` | Задаёт фон, реплику и одного персонажа. Пустой путь к спрайту скрывает персонажа. |
| `UpdateChoices(c1, c2, c3, c4)` | Устанавливает отображаемые кнопки выбора. |
| `TickEngine(deltaTime)` | Обрабатывает события и кадр отрисовки; возвращает `false`, если окно закрыто или ещё не создано. Вызывается игровым циклом. |
| `SetFontSize(size)` | Изменяет размер текста и кнопок. |
| `SetTextRevealSpeed(charactersPerSecond)` | Задаёт скорость появления текста; 0 отключает анимацию. |
| `PlayMusic(path)` / `StopMusic()` | Запускают зацикленную фоновую музыку или останавливают её. |
| `PlaySound(path)` / `StopSounds()` | Проигрывают и останавливают независимые звуковые эффекты. |
| `GetLastErrorMessage(buffer, capacity)` | Забирает и очищает очередь ошибок загрузки ресурсов как UTF-8. |
| `SetMusicVolume(volume)` | Задаёт громкость в диапазоне 0–100. |
| `StartMusicFadeOut(seconds)` | Плавно останавливает текущую музыку. |
| `SetCharacterAnimation(name)` | Выбирает `None`, `FadeIn`, `SlideLeft`, `SlideRight` или `Bounce` для следующей отрисовки персонажа. |
| `ShakeScreen(seconds, intensity)` | Запускает затухающую тряску окна. |
| `FlashScreen(hexColor, seconds)` | Показывает затухающую цветную вспышку. |
| `RegisterChoiceCallback(callback)` | Регистрирует C# callback, получающий индекс нажатой кнопки выбора. |
| `RegisterClickCallback(callback)` | Регистрирует C# callback обычного щелчка, используемый для продолжения диалога. |
| `RegisterHotkeyCallback(callback)` | Регистрирует быстрые команды сохранения F5 и загрузки F9 в первый слот. |
| `RegisterUiActionCallback(callback)` | Регистрирует действия верхней панели: сохранение, загрузка, история, AUTO, HIDE UI и SKIP. |
| `SetGameUiState(flags)` | Включает/выключает режимы скрытого диалога, AUTO, SKIP и истории. |
| `SetSaveMenuState(mode)` / `SetSaveSlotInfo(slot, text, exists)` | Открывают нативное окно слотов и задают подпись/наличие сохранения. |
| `SetPlaybackState(seen, isChoice)` | Задаёт, была ли реплика просмотрена, и блокирует автопереход на узле выбора. |
| `AddDialogueHistory(speaker, text)` | Добавляет реплику в историю игрового окна. |

Callback-ы вызываются из цикла `TickEngine`. C# обёртка передаёт события в UI
через диспетчер Avalonia; обновления ядра сериализуются на потоке preview.
Строковые параметры C ABI кодируются как UTF-8, соглашение вызова — Cdecl;
возвращаемый C++ `bool` у `TickEngine` маршалится как однобайтовый bool.
Ошибки загрузки фона, спрайта, музыки и SFX считываются C# обёрткой как
UTF-8-диагностики и показываются в редакторе/окне player.

## Пока не входит в проект

- Настраиваемая экранная клавиатура, отдельная настройка громкости/SFX внутри
  игры, пользовательские темы и локализация текста интерфейса.
- Отмена/повтор действий редактора, поиск по графу, проверяемый CI-релиз,
  таймлайн анимаций, несколько персонажей/слоёв и панорамирование камеры.
- Полноценный браузер ресурсов: сейчас предусмотрен импорт в `Assets`, но нет
  предпросмотра, тегов, очистки неиспользуемых файлов или пакетного импорта.
- Для релиза следует выполнить GUI-приёмку на чистой Windows x64 системе,
  проверить загрузку/воспроизведение выбранных форматов и соблюсти лицензии
  сторонних компонентов. Smoke-пакет не является готовой пользовательской
  игрой без авторской истории и ресурсов.
